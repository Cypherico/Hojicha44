# Hojicha44 hand-tuned copper manifest — the authoritative preserve set of
# the board generators.
#
# pcb/generators/gen_pcb.py keeps ONLY copper blocks whose signature (kind,
# net, layer, geometry) matches a line in this file; every other copper item
# is router-owned and regenerated wholesale on every run. The router may
# change freely: the preserve set no longer depends on reproducing it.
#
# To hand-tune copper: edit the board, commit it, review the build log's
# census, and capture the offending items' lines into this file (regen with
# PCB_KEPT_DEBUG=1 prints dropped items paste-ready). A manifest line the
# committed board does not contain is a hard error. Sections scope items to
# a half ([Left]/[Right]); regen refuses nothing, but uncommitted
# working-board changes are archived to opencode/ first; extraction reads
# the committed baseline only.
#
# The r14 Choc footprint correction relocates matrix pads and holes.
# Both halves are fully rerouted. See the r13 revision of this file for
# the previous hand-routed segments and their provenance.
